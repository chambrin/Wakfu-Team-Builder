## Ordre de progression recommandé

```
Niv. 1–20   → Introduction (Rii + Astrub)
Niv. 20–45  → Nations (5 chapitres)
Niv. 15–36  → Annexes Introduction (Confrérie, Otomaï)
Niv. 36–50  → Tour Minérale + Ereboria
Niv. 45–145 → Mont Zinit Partie 1 (en parallèle des îles)
Niv. 50–120 → Îles Aventures (Domaine Sauvage → Wabbits)
Niv. 100+   → École d'Huppermagie (30–130)
Niv. 126+   → Éliocalypse Chapitres 1–2
Niv. 140+   → Dimensions Divines + Mont Zinit Partie 2
Niv. 141+   → Dofus Primordiaux (long terme)
Niv. 186+   → Mont Zinit Partie 3 + Éliocalypse Chapitres 3–5
```
