# 🎁 Récompenses & Clés de Donjon

## Vue d'ensemble du système de récompenses

Les donjons de Wakfu offrent plusieurs types de récompenses selon le mode de jeu choisi (Stasis, compétitif, modulé). Comprendre ce système permet d'optimiser ses sessions de farm.

---

## Types de récompenses

### 1. Équipements
Les équipements droppent directement depuis les coffres de fin de donjon.

| Rareté | Stasis requis | Description |
|--------|--------------|-------------|
| **Commun** | 1+ | Équipements basiques |
| **Peu Commun** | 1+ | Légèrement meilleurs stats |
| **Rare** | 1+ | Stats plus intéressantes |
| **Mythique** | 1+ | Équipements puissants de la tranche |
| **Légendaire** | 3+ | Équipements très recherchés |
| **Épique** | 3+ | Parmi les meilleurs du niveau |
| **Relique** | 3+ | Les équipements les plus puissants |

### 2. Ressources de craft
- Ingrédients pour la fabrication d'équipements et consommables
- Matières premières tombant des monstres dans le donjon
- Utilisés par les métiers (Équipementier, Bouclier, etc.)

### 3. Sublimations via Stèles
- 3 stèles par donjon en mode compétitif
- Chaque stèle donne une sublimation unique liée au donjon
- Certaines sublimations parmi les plus puissantes du jeu

### 4. Éclats de Sublimation
- Monnaie obtenue en mode compétitif
- Quantité basée sur le Stasis et la performance (nombre de tours)
- Échangeables contre des sublimations dans des PNJ dédiés

### 5. Coffres mensuels
- Obtenus en mode compétitif au fil du mois
- Contiennent des ressources et équipements supplémentaires
- Récompenses renouvelées chaque mois

## Clés d'accès aux donjons

### Fonctionnement
Certains donjons nécessitent une **clé** pour y accéder. Sans clé, l'entrée est impossible.

### Types de clés
| Type | Comment l'obtenir |
|------|-------------------|
| **Clé de base** | Craft par les métiers (Bouclier, Équipementier) |
| **Clé rare** | Drop de monstres spécifiques dans la zone |
| **Clé d'événement** | Disponibles uniquement pendant des événements saisonniers |

### Craft des clés
Les clés sont craftées par les **Boucliers** (Shieldsmith) ou via d'autres métiers selon le donjon. Les ingrédients sont collectés dans la zone correspondante.

```
Exemple de cycle de clé :
Collecter ressources de zone → Craft clé → Entrer en donjon → Obtenir loot + ressources → Re-craft clé
```

## Coffres de donjon

### Coffre principal (fin de donjon)
Le coffre de fin de donjon s'ouvre après avoir vaincu le boss. Il contient :
- Équipements aléatoires selon la rareté disponible au Stasis choisi
- Ressources de la zone
- Potentiellement : éclats (en mode compétitif)

### Coffres intermédiaires
Certains donjons ont des **coffres intermédiaires** entre les salles. Ils contiennent généralement :
- Ressources
- Équipements de rareté inférieure

### Taux de drop
Le taux de drop est influencé par :

| Facteur | Impact |
|---------|--------|
| Stasis 1 | Taux de base (~60%) |
| Stasis 3 | ~188% de taux de drop |
| Stasis 5 | ~250% |
| Stasis 8 | ~400%+ |
| Mode compétitif max | Jusqu'à 710% |
| Prospection (Enutrof) | Bonus supplémentaire sur le drop |
| Succès bonus en combat | Potentiellement +drop |

## Stèles de Sublimation — Détail

### Qu'est-ce qu'une stèle ?
Une stèle est un objet spécial obtenu dans un donjon en mode compétitif qui, une fois acquise, donne une **sublimation** au personnage.

### Fonctionnement des 3 stèles
Chaque donjon possède 3 stèles numérotées :

```
Stèle 1 → Sublimation A (souvent la plus accessible)
Stèle 2 → Sublimation B (intermédiaire)
Stèle 3 → Sublimation C (souvent la plus puissante / conditionnelle)
```

### Conditions d'obtention des stèles
Les stèles peuvent nécessiter de :
- Compléter le donjon en mode compétitif
- Atteindre un Stasis minimum
- Réaliser le donjon en un nombre limité de tours
- Se moduler à un certain niveau
- Accomplir un objectif secondaire pendant le combat (ne pas tuer un ennemi, finir en X tours, etc.)

### Types de sublimations de donjon
- **Offensives** : augmentent les maîtrises ou dégâts
- **Défensives** : donnent des boucliers ou résistances
- **Utilitaires** : améliorent la gestion des ressources (PA, PM)
- **Conditionnelles** : effets puissants sous certaines conditions

## Mode Compétitif et récompenses

### Activer le mode compétitif
- S'active au moment de rejoindre le donjon
- Toute l'équipe doit activer le mode pour valider les scores
- Enregistre la performance dans les **Ladders PVM**

### Récompenses exclusives mode compétitif
1. **Stèles de sublimation** — 3 par donjon
2. **Éclats de sublimation** — selon performance
3. **Coffres mensuels** — progression mensuelle
4. **Accès Stasis 20+** — pour aller au-delà du Stasis 10 de base

### Ladders PVM
Les classements publics affichent :
- Équipes ayant complété le donjon
- Composition des équipes
- Stasis atteint
- Nombre de tours utilisés
- Permet de s'inspirer des meilleures compositions

## Optimiser ses récompenses

### Stratégie farm équipements
1. Identifier le donjon ayant le drop que vous cherchez
2. Monter au Stasis 3 minimum (accès Légendaire/Épique/Relique)
3. Activer le mode compétitif si le niveau vous le permet
4. Répéter avec une composition adaptée (Enutrof recommandé pour le drop)

### Stratégie sublimations
1. Identifier la sublimation cible et son donjon
2. Activer le mode compétitif obligatoirement
3. Vérifier les conditions de la stèle (tours, Stasis requis, objectif spécial)
4. Préparer la composition en conséquence

### Stratégie éclats
1. Faire les donjons du niveau cible en mode compétitif
2. Viser un Stasis élevé pour maximiser les éclats obtenus
3. Finir en peu de tours (bonus d'éclats sur performance)
4. Accumuler et échanger dans les PNJ d'éclats

---

## Calendrier des récompenses mensuelles

Les coffres de mode compétitif se rechargent **chaque mois**. La stratégie optimale :

```
Début de mois → Faire les donjons cibles en compétitif Stasis élevé
Milieu de mois → Récupérer les récompenses, refaire si bonus disponible
Fin de mois → Dernières runs avant reset mensuel
```
