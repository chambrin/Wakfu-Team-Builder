# 🏰 Donjons Niveaux 216 – 230

> Tranche end-game ultime — Le sommet de la progression de Wakfu. Ces donjons représentent le contenu le plus difficile du jeu. Seules les équipes d'élite peuvent y progresser en Stasis élevé.

## Phytomorphe

**Niveau** : 216–222
**Zone** : Bonta (forêt ancienne)
**Boss** : Phytomorphe Ultime

### Description
Le Phytomorphe est une créature végétale ayant absorbé des pouvoirs de plusieurs autres entités. Donjon de transition vers le end-game ultime.

### Mécaniques notables
- Le Phytomorphe Ultime peut se transformer en copie d'un membre de l'équipe, adoptant ses capacités
- Quand il copie un DPT, il inflige des dégâts massifs — gérer cette transformation en priorité
- Quand il copie un tank, il devient très résistant — changer de cible temporairement
- Des lianes envahissent le terrain progressivement, réduisant l'espace disponible

### Phases du boss
1. **Phase végétale** (100–60% PV) : attaques à portée, création de lianes
2. **Phase de transformation** (60–30% PV) : copie aléatoire d'un membre de l'équipe
3. **Phase finale** (<30% PV) : toutes les capacités précédentes simultanément

### Composition recommandée
- DPT polyvalents capables de cibler différentes compositions ennemies
- Healer très robuste pour la phase finale
- Tank avec armures pour les phases de copie DPT

### Récompenses principales
- Set Phytomorphe niveau 216–222 — équipements de prestige
- Sublimations Phytomorphe parmi les plus puissantes du jeu
- Récompenses de Boss Ultime en mode modulé

## Vidéants

**Niveau** : 220–226
**Zone** : Brakmar (abîmes)
**Boss** : Vidéant Suprême

### Description
Les Vidéants sont des entités qui se nourrissent de la vision — combattre dans leur antre est une expérience de privation sensorielle. L'un des donjons les plus redoutés du jeu.

### Mécaniques notables
- La visibilité est réduite à 2 cases autour de chaque personnage — coordination aveugle nécessaire
- Le Vidéant Suprême peut voler la visibilité d'un personnage (il devient aveugle totalement)
- Des phares de lumière sur le terrain peuvent être activés — mais illuminer une zone attire les Vidéants

### Stratégies
- **Rester groupés** : maximise la visibilité partagée
- **Activer les phares** : risqué mais nécessaire pour voir les zones clés
- **Jeu de mémoire** : mémoriser le layout du terrain pour naviguer dans l'obscurité

### Composition recommandée
- Personnages avec des sorts à courte portée très efficaces (mêlée recommandée)
- Support capable de soigner en aveugle (zones de soin)
- Éviter les DPT purement longue portée (inefficaces sans visibilité)

### Récompenses principales
- Set Vidéant niveau 220–226 — les équipements les plus puissants de la tranche
- Sublimations exceptionnelles
- Titres de prestige pour les Stasis élevés

## Démhorribles

**Niveau** : 224–230
**Zone** : Brakmar (abîmes profonds)
**Boss** : Démhorrible Ancien

### Description
Le donjon de niveau maximum du jeu. Les Démhorribles sont des entités démoniaques anciennes dont la puissance dépasse l'entendement. Le Démhorrible Ancien est considéré comme le boss le plus difficile du jeu.

### Mécaniques notables
- **Mécanique de corruption** : chaque tour, les personnages accumulent de la corruption. À 100%, ils deviennent temporairement Démhorribles (incontrôlables, attaquant leurs alliés).
- **Niveaux de menace** : le Démhorrible Ancien gagne en puissance selon le nombre de joueurs non corrompus
- **Phase de démence** (<40% PV) : la corruption s'accumule deux fois plus vite, dégâts massifs en zone chaque tour
- Des portails de purification permettent de retirer la corruption — mais les utiliser coûte un tour entier

### Phases du boss
1. **Phase de siège** (100–70% PV) : corruption lente, mécaniques de placement
2. **Phase d'intensification** (70–40% PV) : corruption accélérée, invocations démoniaques
3. **Phase de démence** (<40% PV) : corruption rapide, dégâts de zone, purification critique

### Gestion de la corruption
```
Tour 1–3   : Accumuler normalement sans paniquer
Tour 4–6   : Se purifier avant d'atteindre 80% de corruption
Phase 2+   : Alterner purification et attaques en équipe coordonnée
Phase démence : Priorité purification — DPT réduit mais survie assurée
```

### Composition recommandée (End-game optimal)
| Slot | Classe | Justification |
|------|--------|---------------|
| 1 | **Féca** | Armures massives pour absorber la phase de démence |
| 2 | **Pandawa** | Gestion du placement + deuxième tank |
| 3 | **Eniripsa** | Heal pur pour maintenir la vie malgré la corruption |
| 4 | **Osamodas** | Buffs PA pour maximiser les tours de purification+DPT |
| 5 | **Iop** ou **Sram** | DPT extrêmes pour passer la phase de démence vite |
| 6 | **Zobal** | Armures + Soin + Retrait rés pour la survie totale |

### Récompenses principales
- **Set Démhorrible** — les équipements les plus puissants du jeu
- **Sublimations Légendaires** exclusives au contenu niveau 230
- **Titres de prestige ultime** pour les clears en Stasis élevé
- **Récompenses mensuelles** spéciales en mode compétitif
- Accès aux **Stasis 20+** (mode compétitif avancé)

## End-game et au-delà

### Contenu Stasis 20+ (mode compétitif avancé)
En ayant complété les Stasis 10 en mode compétitif, l'accès aux Stasis supérieurs se débloque :

```
Stasis 10 complété  → base débloquée
Stasis 20 complété  → débloque Stasis 21-30
Stasis 30 complété  → débloque Stasis 31-40
Stasis 40 complété  → débloque Stasis 41-50
```

Ces Stasis supérieurs représentent le contenu de prestige absolu du jeu.

### Objectifs end-game
1. Compléter tous les donjons de la tranche 216–230 en mode compétitif
2. Optimiser les builds avec les meilleurs équipements (Relique complet)
3. Monter progressivement le Stasis dans chaque donjon
4. Viser les **Ladders PVM** — être dans le top des meilleures équipes du serveur
5. Maîtriser le contenu de Boss Ultime en modulation

---

## Conseils pour le end-game ultime

- Le **Démhorrible Ancien** est le test ultime — toute l'équipe doit avoir des builds parfaitement optimisés
- Les **Vidéants** imposent une refonte de la composition habituelle — adapter sa stratégie est indispensable
- Étudier les **Ladders PVM** pour comprendre les compositions d'élite
- La communication d'équipe (vocal) est quasiment obligatoire pour les Stasis 8+ ici
- Participer aux **événements saisonniers** pour compléter certains équipements manquants
