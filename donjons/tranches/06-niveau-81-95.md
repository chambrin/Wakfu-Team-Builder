# 🏰 Donjons Niveaux 81 – 95

> Tranche avancée basse — Les donjons requièrent une vraie organisation de groupe et la connaissance des mécaniques de boss devient indispensable.

## Hammamamoule

**Niveau** : 81–87
**Zone** : Sufokia
**Boss** : Moule-Hammam

### Mécaniques notables
- Donjon aquatique avec des zones de vapeur qui obscurcissent la vision
- La Moule-Hammam peut se fermer hermétiquement (invulnérable) pendant quelques tours
- Gérer les phases de vulnérabilité pour concentrer les dégâts

### Récompenses principales
- Équipements nautiques niveau 81–87

---

## Sliptorium

**Niveau** : 82–88
**Zone** : Sufokia
**Boss** : Slip Glissant

### Mécaniques notables
- Terrain glissant — les déplacements peuvent être imprévisibles
- Le Slip Glissant peut pousser tous les personnages dans une direction
- Gestion de terrain : anticiper les glissades avant d'agir

### Composition recommandée
- Personnages avec des compétences d'ancrage ou de résistance aux poussées
- Placeur capable de repositionner après les glissades

### Récompenses principales
- Équipements niveau 82–88

---

## Misolée

**Niveau** : 84–90
**Zone** : Bonta
**Boss** : Miso

### Mécaniques notables
- Décor japonisant, murs en papier
- Miso peut traverser les murs (les sorts non)
- Adaptation des angles de tir nécessaire

### Récompenses principales
- Set Miso — équipements asiatiques niveau 84–90

---

## Scarrière Abandonnée

**Niveau** : 85–92
**Zone** : Brakmar
**Boss** : Scarafresh

### Mécaniques notables
- Donjon minier avec des éboulements possibles
- Le Scarafresh peut enterrer des personnages, les rendant inaccessibles temporairement
- Les enterrés perdent des PV chaque tour — les dégager rapidement est prioritaire

### Récompenses principales
- Ressources minières + équipements niveau 85–92

---

## Caverne des Slekymoses

**Niveau** : 87–93
**Zone** : Amakna
**Boss** : Slekymose Reine

### Mécaniques notables
- Les Slekymoses laissent de la bave sur le sol (zone ralentissante)
- La Reine peut coller un personnage au sol (immobilisation totale)
- Gérer la bave : ne pas passer dessus sans nécessité

### Récompenses principales
- Équipements d'agilité niveau 87–93

---

## Château de Wagnar

**Niveau** : 88–94
**Zone** : Brakmar
**Boss** : Wagnar

### Mécaniques notables
- Wagnar est un chevalier avec une invulnérabilité frontale
- Il faut le positionner de dos pour infliger des dégâts normaux
- Le **Pandawa** est quasi-indispensable pour retourner le boss

### Composition recommandée
- **Pandawa** obligatoire pour le retournement
- DPT dos (Sram idéalement) pour exploiter la position dos
- Healer pour tenir face aux chevaliers gardiens

### Récompenses principales
- Set chevaleresque niveau 88–94

---

## Académie Trool

**Niveau** : 90–95
**Zone** : Amakna
**Boss** : Grand Trool

### Mécaniques notables
- Le Grand Trool peut transformer les personnages en étudiants (forme moins puissante)
- Les Trools étudiants dans la salle donnent des buffs au Grand Trool
- Priorité : éliminer les étudiants Trool avant de combattre le boss

### Récompenses principales
- Équipements d'intelligence niveau 90–95

---

## Nécropoil de Morbax

**Niveau** : 92–95
**Zone** : Brakmar
**Boss** : Morbax

### Mécaniques notables
- Donjon non-mort avec des résurrections de masse
- Morbax ressuscite les ennemis tombés à chaque fin de tour
- Nécessite de tuer tous les ennemis dans le même tour ou d'éliminer Morbax en priorité

### Récompenses principales
- Équipements nécromantiques niveau 92–95

---

## Antre du Meulou

**Niveau** : 93–95
**Zone** : Sufokia
**Boss** : Meulou Ancestral

### Mécaniques notables
- Le Meulou Ancestral est un boss avec des gardes qui tournent autour de lui
- Les gardes absorbent les dégâts dirigés vers le boss
- Coordination nécessaire pour éliminer les gardes aux bons moments

### Récompenses principales
- Équipements niveau 93–95

---

## Conseils pour cette tranche

- Le **Pandawa** devient quasi-indispensable dans cette tranche pour les mécaniques de placement dos
- Les **résurrections et invocations ennemies** requièrent des DPT AoE (Huppermage, Cra zone)
- Investir dans la **résistance** — les dégâts ennemis augmentent significativement
- Le mode compétitif est vraiment intéressant à partir de ce niveau — les sublimations de la tranche 81–95 sont pertinentes jusqu'au milieu du jeu
